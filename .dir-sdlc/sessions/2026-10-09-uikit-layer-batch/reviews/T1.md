## Advisory findings

**A1 — `Edit` strips trailing whitespace from `new_string`: a third tool mechanism, distinct from the `Write`/`sed -i` family.** It leaves line endings intact and silently drops the requested indent, and the tool reports "No changes to make" when the only difference is trailing tabs. The implementer's character-keyed 34-edit workaround — keying each replacement on the line's first text character so the tabs are never trailing — is the right shape and it worked: all 116 lines carry exactly two tabs. **The reviewer notes the existing `project_write_tool_destroys_crlf` note does not cover it, because the failure signature differs: no line-ending damage, just a missing indent that only a tab-form grep catches.** Independently confirmed by the orchestrator and saved to project memory as `project_edit_strips_trailing_tabs`.

**A2 — the `grep -c $'\r$'` divergence resolves, and the register must call it environment-dependent.** On the reviewer's own fixtures it returns **3 on pure-CRLF, 3 on pure-LF and 3 on MIXED** — the file's line count regardless of content, exactly as the criterion records and as the orchestrator measured — **not** the 0/0/0 the implementer measured. Both parties are right that it discriminates nothing. The register entry should state the specific failure mode is **environment-dependent** (line-count-regardless in the orchestrator's and reviewer's shells, constant-zero in the implementer's) rather than assert either, since the only portable conclusion is that it must not be used.

**A3 — the nested-paren trap defeats naive brace detectors by more than one route, and this is a second route worth recording.** The reviewer's first-draft detector missed `:279` **not** through paren-balance arithmetic but through its same-line-statement heuristic: `\)\s*\S` matched the `) &&` **inside** the header and classified the site as the `if (x) return;` form. `measurement.md` section 4 records the balance-arithmetic route; this is an independent second way the same defect class produces a confident false negative. **A detector needs the *matching* close paren, not the first one.**

**A4 — no contract violation.** The diff touches only the single owned file, and the implementer's writes outside the worktree went to its own scratch directory.
