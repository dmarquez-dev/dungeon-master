## Findings

**B1 — raised, then withdrawn.** The reviewer first found criterion 12 not met, the report carrying no `AUDIT OUTCOMES` block. **The cause was an orchestrator defect, not an implementer one**: the dispatch summarised T1's report instead of handing it over verbatim, and the excerpt stopped before the block. The reviewer was re-dispatched with the verbatim block and re-judged criterion 12 against contract §6 and §2 — form, vocabulary, ownership, and each evidence claim against its own reproduction — and withdrew B1. Not a revision round: no implementer was re-dispatched and the diff never changed.

**A1 (advisory, carried).** `GreaterThanZeroConverter.Convert` returns `true` for the sentinel when `parameter` is `"Invert"` — `GreaterThanZeroConverter.cs:38-46` computes `value is int n && n > 0` (`false` for the sentinel) and then negates it, so an inverted binding on an unresolved path *shows* the element. The same defect class `MASTER-007` fixes in `NotNullConverter`, surviving in the converter `UIKIT-004` declares immune. **Two live consumers**, confirmed by the orchestrator: `DungeonDetailPage.xaml:151` and `DungeonListPage.xaml:115` (the "Add at least one floor before starting a session" overlay). Outside criterion 7's scope, which asks only for the non-inverted case. Explicitly **not** a `contradicts`: `UIKIT-004`'s written claim concerns the bare `value is int n` test, which is genuinely immune, so nothing written is falsified.

**A2 (advisory, actioned at commit).** The two new test files are untracked and absent from `git diff`; they must be staged explicitly or the tests ship as nothing.

**A3 (advisory, recorded).** The reviewer independently hit the `sed -i` trap while reverting for its red step: under MSYS it rewrote `NotNullConverter.cs` to LF and produced ~20 `error IDE0055` under `TreatWarningsAsErrors` before any test could run. `perl -i -pe` preserved CRLF. The implementer's CRLF normalisation was necessary, not cosmetic. Second consecutive sub-session this trap has cost time.

**A4 (advisory, correction to an evidence line).** T1's `MASTER-034` evidence says the doc blocks went "21 lines to 6"; measured, the new blocks are lines 48–54 = **7**. Old block 48–68 = 21 is right. Worth correcting before T9 copies the evidence line into `docs/audit/00-master-index.md`, where a wrong count outlives the session. Bears on nothing either status depends on. (The reviewer also corrected its own two earlier awk counts here, each one short because the anchor consumed the `/// <summary>` start line.)
