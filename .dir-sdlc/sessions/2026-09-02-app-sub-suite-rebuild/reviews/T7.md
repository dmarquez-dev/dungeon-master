## The two undisclosed-by-criteria behaviour changes

**A2 — `StaleValueExceptions` now searches attribute values and element text rather than the file's
bytes. Sound, keep.** It strictly narrows what keeps an exemption alive, and the failure mode it
closes is real: under `File.ReadAllText(path).Contains(value)`, **an exception's own explanatory
comment quoting the number was enough to keep it green forever.** Criterion 6 governs allow-list
*entries*, which are unchanged; all four still pass; the change was disclosed.

**A3 — `HasDocumentingComment` re-expressed as a line window over `XComment`. Accept.** The reviewer
checked the arithmetic rather than only the greenness: the old form walked back over 8 `\n` bounded by
the comment's `-->`; the new takes the comment's start line plus the newline count of its value as the
closing line, requiring `closing <= line && line - closing <= 8`. **Same window, same closer-based
bound** — and strictly more accurate in one respect: a literal `-->` inside an attribute value can no
longer be mistaken for a comment closer. T7 was right that a control-flow rewrite under a green test
deserves disclosure, and right that this one is safe.
