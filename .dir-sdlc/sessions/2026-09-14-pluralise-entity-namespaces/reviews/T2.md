## A constraint this review surfaced, for the backlog

Defect injection is the strongest evidence a reviewer can produce — it is what made T1's review convincing — but it is **unsafe precisely when concurrency is in use**, because the worktree is shared and a deliberately broken intermediate state can corrupt a peer mid-build. T2 and the orchestrator reached this independently. The framework does not currently name the tension; the workable form is injection into a scratch copy, or reliance on a positive control already run inside a frozen contract, with the substitution disclosed either way.
