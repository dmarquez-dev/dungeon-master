## Advisory findings

- **T1 reported an injection that reddened two tests without naming the second.** The count was
  accurate and the run clean, but an unnamed extra failure is the same shape an inert injection takes,
  and this project has recorded that confusion before. Name every failure in an injection run.
- **`grep -c $'\r$'` returned 0 on a file with 111 CRLF and 0 bare LF.** The recorded leading-CR grep
  pitfall, firing live inside a line-ending audit. T1's figures were right; the method was not. The
  reliable check is a binary count — `b.count(b'\r\n')` versus `b.count(b'\n')`.
- **The CRLF prohibition is load-bearing, confirmed the hard way.** A `sed -i` edit of
  `FloorReorderDrop.cs` stripped every CRLF and turned the build red with ~30 `IDE0055` errors.
  Reverted from a scratch backup before any test run that mattered.
- `DungeonDetailPage.xaml.cs:861` passes `args.TargetNumber` while `:2284` passes
  `decision.TargetFloorNumber`. Both correct, both now covered; the shape difference may puzzle a later
  reader.
- The placement deviation from round 0's option 1 is correct; the reviewer verified the stated reason
  without spending a lookup, because the orchestrator had already verified it.
