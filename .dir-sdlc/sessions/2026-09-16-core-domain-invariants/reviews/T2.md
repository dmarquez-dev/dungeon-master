## Why criterion 7's mirror run mattered

T2's own discrimination removed only the `UpdateNumber` guard. That proves `UpdateNumber` is covered, but a
single test standing in for **both** guards would survive it in one direction — the constructor tests could
have been passing for a reason unrelated to the constructor guard. The reviewer was asked to run the mirror
case and did: constructor guard removed alone, exactly the two constructor tests red, both `UpdateNumber`
tests green. **The two guards are independently covered**, which is what criterion 1 actually claims and what
a one-sided run cannot establish.
