## Ruling on criterion 9 — met by substitution, and the criterion's wording is the defect

**The reviewer applied the criterion's literal injection itself** rather than accepting T4's account. The bare
literal `"scale"` in place of `paramName` fails to build:

```
PlacedObject.cs(96,5): error CA1507: Use nameof in place of string literal 'scale'
```

`Directory.Build.props:5` sets `TreatWarningsAsErrors`, with `AnalysisLevel 10.0`, and `.editorconfig` carries
no CA1507 override — **independently confirmed by the orchestrator as well.**

> **The criterion's literal wording specifies an injection that cannot produce a test failure in this
> repository, because no test ever runs. That is a defect in the criterion's wording, not in the work.**

T4's substitution — `paramName` -> `nameof(scale)` inside the helper — is **the same defect class under the
only spelling that compiles**: the helper reports its own parameter name instead of the caller's, which is
precisely the defect criterion 4 names as the one this extraction risks. It produced the required failure and
carried a genuine positive control (the 9 passing included both constructor `ParamName` assertions, which must
stay green under this defect). The reviewer reproduced all of it — same 6/9/15 split, same messages.

**No escalation raised**, because nothing needs a decision: the criterion's purpose is fully satisfied and the
only latitude taken was choosing the compiling spelling of the named defect.

## Advisory finding

**A1. `ex.Message.Should().Contain("5")` cannot fail, and does not check what it appears to check.**
`PlacedObjectTests.cs:95`, against `ObjectScale.Min = 0.25f`.

The message template renders as `Scale must be between 0.25 and 4.` — which **already contains the digit `5`
inside `0.25`.** So the assertion passes regardless of whether the rejected value reaches the message,
**including under the two-argument overload that drops `ActualValue` entirely.**

Advisory rather than blocking: criterion 6 does not rest on it. The load-bearing assertion is
`ex.ActualValue.Should().Be(5.0f)`, which the reviewer proved discriminating by injection. If tightened later,
`Contain("Actual value was 5")` would test the intended property; **the digit-substring form never can.**

> This is the "an assertion that cannot fail" shape, found inside a passing suite, in a test added by this
> session. It was found by a reviewer probing an assertion no criterion required it to examine.
