## Advisory findings

1. **The primary-palette type summary reads as more complete than the code.** It says the view offers "the
   objects of the loaded pack as rows of category chips"; `:265-266` and `:292-301` show each row holds at
   most seven chips (`cols * 2 - 1`) with an expander in the eighth slot when more exist. **No universal word
   is used and the expander is documented**, so this is wording, not a false assertion.
2. **One sentence is true only through a non-local chain.** "Lists every object of a single category" holds
   because `ObjectPackRegistry.cs:32-36` builds `Categories` by grouping the `paths` dictionary, so every
   kind in a category is in `Paths` and the asset filter drops nothing. **The reviewer verified that chain
   and judged the row met on it**, flagging only that the sentence becomes false the day categories stop
   being derived from paths — and **nothing local to the file would reveal it.**
3. **The preserved `LoadFailed` block breaks one sentence across three `///` lines**, contrary to
   `dotnet-format.md:378`. Criterion 3 required byte-for-byte preservation, so this task could not fix it,
   and criterion 5 binds only blocks this task wrote. **Judged independently of the sibling T1 precedent**,
   and the reviewer distinguished them correctly: T1's violation is in prose it authored, this one in prose
   it was ordered not to touch.
4. **One sentence sits oddly on its member.** "Nothing here throws if the call is skipped" is true but sits
   on `Populate`, whose body does not run at all when the call is skipped; the constructor sentence already
   carries the consequence. **Wording only — and the wording does satisfy criterion 8(ii), which is the point
   that mattered.**
